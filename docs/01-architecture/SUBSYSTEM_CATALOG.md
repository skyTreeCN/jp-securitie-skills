# サブシステム・カタログ v0.4

**as-of:** 2026-09-08  
**Status:** Draft for Architecture Freeze

> サブシステムは「業務機能/責務」の単位のみ。現物/信用等の取引種別、株式/債券/投信等の商品は含めない。IDはv1.0 Architecture FreezeまでProvisionalとする。

## 業務サブシステム

### A. 顧客・口座・営業

| ID | サブシステム | 主責務 |
|---|---|---|
| SS01 | 顧客属性管理 | 顧客の基本属性、本人確認/KYC、税務属性、居住性、職業、投資経験、適合性属性等を管理する。 |
| SS02 | 口座管理 | 総合口座・各種勘定口座の開設、状態、閉鎖、名寄せ、口座階層を管理する。 |
| SS03 | 契約・サービス管理 | 特定口座、NISA、信用口座、電子交付等の契約・サービス選択と適用期間を管理する。 |
| SS04 | 営業組織・担当者・チャネル管理 | 部店、営業員、IFA/仲介、対面/ネット等のチャネル属性と帰属を管理する。 |

| SS05 | 銘柄管理 | 銘柄コード、商品属性、市場、税区分、権利属性、取扱可否等の銘柄マスターを管理する。 |
| SS06 | 市場・営業日管理 | 市場区分、取引日、休業日、受渡営業日、締切等のカレンダーを管理する。 |
| SS07 | 時価・為替レート・基準価額管理 | 時価、基準価額、為替レート、金利等の評価・計算基礎値を管理する。 |
| SS08 | 制度・料率・業務パラメータ管理 | 税率、手数料率、保証金率、決済サイクル等の制度・業務パラメータを版管理する。 |

## サブシステムではないもの

- 信用取引 / 現物取引 → 取引種別
- 株式 / 債券 / 投資信託 → 商品
- IPO/PO → 取引/サービス種別。機能としてはSS11が担当
- 先物/Option → 商品・取引種別。注文約定、建玉、担保、清算、決済等に分解
- 貸借/Repo → TR08として既存SSへRuleを追加
