# サブシステム別設計書一覧

## 1. 位置付け

本ディレクトリには、全体設計で定義した各サブシステムの詳細設計書を配置する。

設計単位は次の48論理サブシステムとする。

- 業務サブシステム: SS01～SS42
- 共通サブシステム: CS01～CS06

設計書を正本とし、`skills/` 配下の `SKILL.md` はAIが当該設計知識を利用するための入口とする。

## 2. 標準設計範囲

各サブシステム別設計では、最低限次を明確にする。

1. 目的・責務
2. 対象範囲 / 対象外
3. 業務機能
4. 業務規則
5. 業務状態・ライフサイクル
6. 計算・判定
7. データ正本
8. 入力
9. 出力
10. 対内インターフェース
11. 対外インターフェース
12. 日次・バッチ・締切・業務日付
13. 帳票・データレイアウト
14. 例外・訂正・取消・再処理
15. 会計影響
16. 税務影響
17. テスト観点
18. 出典

### SS26 譲渡益税・特定口座

**状態:** 完成サンプル / 設計可能レベル

配置先:

`SS26-譲渡益税・特定口座/`

構成:

- `譲渡益税・特定口座設計書.md` — 主設計書
- `業務ルール一覧.md` — 税26-R001～R037

- `日次・年次処理設計.md` — 日中、日次締め、年次締め、年度切替
- `権利イベント税務影響.md` — 分割、併合、資本払戻し、組織再編等
- `帳票設計.md` — 特定口座年間取引報告書等の論理レイアウト

## 5. 設計書命名

各サブシステムは原則として次の形式で配置する。

```text
02-サブシステム別設計/
  SS01-顧客属性管理/
    顧客属性管理設計書.md
  SS02-口座管理/
    口座管理設計書.md
  ...
  SS26-譲渡益税・特定口座/
    譲渡益税・特定口座設計書.md
  ...
  CS01-外部接続/
    外部接続設計書.md
```

設計書・補助設計書のファイル名と文書タイトルは日本語を基本とする。
