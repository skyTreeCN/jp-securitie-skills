# サブシステム別設計書一覧

## 1. 位置付け

本ディレクトリには、全体設計で定義した各サブシステムの詳細設計書を配置する。

設計単位は次の48論理サブシステムとする。

- 業務サブシステム: SS01～SS42
- 共通サブシステム: CS01～CS06

## 2. 作成順序

各サブシステム別設計書は、全体設計の責務境界・データ正本・対内外関係を前提として作成する。

標準章立て:

1. 目的・責務
2. 対象範囲 / 対象外
3. 業務機能
4. 業務規則
5. 業務状態・ライフサイクル
6. 計算・判定
7. 入力
8. 出力
9. 対内インターフェース
10. 対外インターフェース
11. バッチ・締切・業務日付
12. 帳票・データレイアウト
13. 例外・訂正・取消・再処理
14. 会計影響
15. 税務影響
16. テスト観点
17. 出典

## 3. 初回詳細化対象

国内株式現物取引の基本業務を成立させるサブシステムから詳細化する。

`SS01 → SS02 → SS03 → SS05 → SS06 → SS08 → SS42 → SS34 → SS09 → SS10 → SS14 → SS16 → SS17 → SS18 → SS21 → SS22 → SS23 → SS24 → SS25 → SS26 → SS27 → SS28 → SS31 → SS32 → SS33 → CS01 → CS02`

## 4. 設計書命名

各サブシステムは原則として次の形式で配置する。

```text
02-サブシステム別設計/
  SS01-顧客属性管理/
    顧客属性管理設計書.md
  SS02-口座管理/
    口座管理設計書.md
  ...
  CS01-外部接続/
    外部接続設計書.md
```

Skill本体は `skills/` に保持するが、設計書の正本は本ディレクトリ配下とする。
