# SS26 譲渡益税・特定口座 テスト観点

**版:** 1.0  
**基準日:** 2026-09-08

---

## 1. テスト方針

SS26は個別計算式だけでなく、**取得→譲渡→損益→徴収/還付→配当通算→年次帳票→訂正**の一貫性を検証する。

テストは次の軸で組み合わせる。

```text
口座区分
× 商品
× 取引種別
× 取得パターン
× 譲渡パターン
× 税務年度
× 権利イベント
× 訂正有無
```

---

## 2. 口座区分

| 観点ID | ケース | 期待結果 |
|---|---|---|
| 税26-T001 | 一般口座 | 特定口座源泉徴収・年間取引報告対象外 |
| 税26-T002 | 特定口座 源泉なし | 損益計算するが源泉徴収しない |
| 税26-T003 | 特定口座 源泉あり | 年初来差額方式で徴収/還付 |
| 税26-T004 | NISA | 課税損益へ流入しない |
| 税26-T005 | 同一顧客に一般+特定 | 取得価額を混合しない |
| 税26-T006 | 同一顧客に複数特定口座 | 口座間を自動通算しない |

---

## 3. 取得価額

- 初回買付のみ
- 同一銘柄を複数回買付
- 同日複数買付
- 一部売却後の再買付
- 全売却後の再買付
- 手数料あり/なし
- 税務算入対象費用/対象外費用
- 1単位取得価額に1円未満端数発生
- 取得価額総額と単価丸め差
- 特定口座内/外同一銘柄
- 他社入庫で取得価額引継ぎ
- 取得価額情報不足入庫
- NISAから課税口座への移管

### 代表計算ケース

```text
100株×1,000円取得
100株×1,200円取得
→ 平均1,100円
50株売却
→ 取得費55,000円
```

期待値を固定し、履歴・残数量・残取得価額まで確認する。

## 4. 譲渡損益

| 観点 | ケース |
|---|---|
| 利益 | 売却益のみ |
| 損失 | 売却損のみ |
| ゼロ | 譲渡価額=取得費+費用 |
| 部分約定 | 複数約定に分割 |
| 一部売却 | 残存取得価額確認 |
| 複数銘柄 | 銘柄別取得価額・口座年次集計 |
| 上場/一般 | 税務区分別集計 |
| 信用 | 差益/差損、現引/現渡境界 |

---

## 5. 源泉徴収・還付

必須シナリオ:

### 税26-T100 利益のみ

```text
1回目利益 +100,000
→ 100,000に対する税を徴収
```

### 税26-T101 利益→損失

```text
1回目 +100,000
2回目 -40,000
→ 年初来 +60,000
→ 過徴収差額を還付
```

### 税26-T102 利益→損失→利益

```text
+100,000 → -40,000 → +30,000
→ 累計必要税額の差分で
  徴収 → 還付 → 再徴収
```

### 税26-T103 年初来赤字

累計所得0として徴収なし。すでに徴収済みなら制度に従う還付額を確認する。

### 税26-T104 税額端数

税率乗算結果に1円未満が生じる境界値を網羅する。

## 7. 配当等損益通算

| ケース | 確認 |
|---|---|
| 配当受入選択なし | SS26通算対象外 |
| 配当受入選択あり・譲渡益 | 不要な通算なし |
| 配当受入選択あり・譲渡損 | 対象配当と通算 |
| 譲渡損>配当 | 通算後課税額0 |
| 譲渡損<配当 | 残額に対する必要税額 |
| 配当複数件 | 年次合計一致 |
| 外国所得税あり | 帳票項目・集計保持 |
| 配当訂正 | 通算/還付再計算 |

- 部分移管

- 移管訂正/取消

## 9. 権利イベント

- 1:2分割
- 1:3分割
- 併合
- 端数金銭交付
- 資本払戻し
- みなし配当あり/なし
- 合併
- 株式交換/移転
- 新株予約権行使
- 償還/解約
- 権利イベント訂正

権利訂正では取得価額だけでなく後続売却・税額・帳票まで再計算されることを確認する。

## 15. 境界値

- 数量1株
- 非常に大きい数量/金額
- 取得価額1円
- 損益±1円
- 税額が0円/1円となる境界
- 丸め直前値 x.000... / x.999...
- 年初来損益が -1 / 0 / +1
- 配当損益通算後が -1相当 / 0 / +1

---

## 16. 完了条件

SS26の主要テスト完了条件:

1. 全主要業務ルールに対応Caseがある。
2. 取得価額→譲渡損益→税額→帳票の期待値が一致する。
3. 訂正・取消後も元帳整合性が保たれる。
4. 日次/年次再実行で二重計上しない。
5. NISA/一般/特定の境界違反がない。
6. 2026/2027税率境界が正しい。
7. 帳票明細と年次集計が一致する。
8. 出典に反する計算ルールが存在しない。
