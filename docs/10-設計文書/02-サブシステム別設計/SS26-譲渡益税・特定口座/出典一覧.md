# SS26 譲渡益税・特定口座 出典一覧

**確認日:** 2026-09-08  
**対象:** SS26 譲渡益税・特定口座  

## 1. 出典利用原則

本サブシステムの税務ルールは、国税庁等の一次情報を優先する。各業務ルールには本書の出典IDを付与し、制度改正時は出典の適用時点と設計ルールの有効期間を同時に更新する。

- A: 法令・政令・省令・法令解釈通達
- B: 国税庁の制度説明・タックスアンサー・源泉徴収実務資料
- C: 国税庁の法定調書様式・記載要領
- D: 金融庁等の制度主管機関資料
- E: 社内実務ノウハウ。一次情報と混同せず、追加時に `社内ノウハウ` と明示する。

## 8. 適用時点管理

税率・様式・対象商品の定義はハードコードせず、最低限以下を有効期間付きで管理する。

```text
税務ルール版
  ├─ ルールID
  ├─ 適用開始日
  ├─ 適用終了日
  ├─ 所得税率
  ├─ 復興特別所得税率
  ├─ 防衛特別所得税率
  ├─ 住民税率
  ├─ 帳票様式版
  ├─ 根拠出典ID
  └─ 検証日
```

特に2027-01-01から、所得税15%に対する付加税の内訳が変更される。源泉徴収の合計税率15.315%自体は変わらないが、内部データでは税コンポーネントを分離管理できる構造とする。
