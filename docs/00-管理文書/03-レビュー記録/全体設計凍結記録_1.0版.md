# 全体設計凍結記録 1.0版

**区分:** 管理文書 / 凍結記録  
**凍結日:** 2026-09-08

## 1. 記録目的

本書は全体設計書ではない。全体設計のレビュー完了時点と、凍結した管理ID・対象範囲を記録するための管理文書である。

## 2. 凍結対象

- 業務サブシステム: SS01～SS42（42）
- 共通サブシステム: CS01～CS06（6）
- 取引種別: TR01～TR11（11）
- 商品: PR01～PR11（11）

業務要件は原則として次の3軸で整理する。

`サブシステム × 取引種別 × 商品`

## 3. 設計内容の正本

設計内容そのものは、次の設計文書を正本とする。

- `docs/10-設計文書/01-全体設計/全体設計書.md`
- `docs/10-設計文書/01-全体設計/システム全体構成図.md`
- `docs/10-設計文書/01-全体設計/業務機能一覧.md`
- `docs/10-設計文書/01-全体設計/業務機能関係図.md`
- `docs/10-設計文書/01-全体設計/外部関係図.md`
- `docs/10-設計文書/01-全体設計/データ正本管理表.md`

本書に設計内容の重複記載は行わない。

## 4. 変更時の扱い

凍結後にサブシステム追加・削除・責務変更を行う場合は、変更管理方針に従い、対象設計書を更新したうえで本記録の版を更新する。
