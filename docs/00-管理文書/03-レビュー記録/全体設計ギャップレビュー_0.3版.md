# 全体設計ギャップレビュー 0.3版

**区分:** 管理文書 / レビュー記録  
**実施日:** 2026-09-08

## 1. レビュー目的

0.3版の論理サブシステム構成について、次を確認した。

1. サブシステム、取引種別、商品が混在していないか
2. 主要な証券業務を端から端まで処理できるか
3. 同一サブシステムに異質な責務が混在していないか
4. 外部インフラとの接続責務が明確か
5. 主要データの正本を一意に定義できるか
6. 独立した状態・残高・法定責任を持つ機能が漏れていないか

## 2. 主な指摘

### 指摘1 約定照合・決済照合の独立

約定・決済の照合状態は、残高・資金の照合や決済フェイル管理とは異なる業務ライフサイクルを持つ。

対応:
- SS40 約定照合・決済照合管理を追加
- SS24は残高・資金照合、例外、決済フェイル管理へ責務を限定

### 指摘2 取引先・決済条件の正本不足

取引先、参加者コード、決済銀行、保管機関、決済口座、SSI等を一元管理する正本が不足していた。

対応:
- SS41 取引先・決済条件管理を追加

### 指摘3 交付書面・同意管理の正本不足

契約締結前・締結時書面、目論見書、電子交付同意、交付証跡等を、取引後帳票とは別責務として管理する必要がある。

対応:
- SS42 交付書面・目論見書・同意管理を追加

## 3. 確認した責務境界

- SS09 注文・約定管理 と SS21 清算管理
- SS09 注文・約定管理 と SS40 約定照合・決済照合管理
- SS40 約定照合・決済照合管理 と SS24 残高・資金照合／例外・フェイル管理
- SS41 取引先・決済条件管理 と SS22 受渡・決済管理
- SS16 顧客勘定管理 と SS17 資金残高・入出金管理
- SS12 建玉管理 と SS18 証券預り・残高管理
- SS20 評価・損益管理 と SS26 譲渡益税・特定口座
- SS25 権利管理 と SS26/SS27 税務機能
- SS32 対客帳票・電子交付 と SS42 交付書面・目論見書・同意管理

## 4. レビュー結果

0.3版の構成にSS40、SS41、SS42を追加し、SS24の責務を見直すことで、主要な責務空白を解消した。

レビュー後の論理構成:

- 業務サブシステム: SS01～SS42
- 共通サブシステム: CS01～CS06

本書は設計書ではなく、設計変更の検討結果を記録する管理文書である。設計内容の正本は `docs/10-設計文書/` 配下とする。
