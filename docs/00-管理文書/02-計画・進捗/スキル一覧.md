# スキル一覧

## 1. 設計書との関係

サブシステム名称・責務の正本は、次の設計書とする。

- `docs/10-設計文書/01-全体設計/業務機能一覧.md`
- `docs/10-設計文書/01-全体設計/業務機能関係図.md`
- `docs/10-設計文書/01-全体設計/データ正本管理表.md`

サブシステム別設計書は次に配置する。

- `docs/10-設計文書/02-サブシステム別設計/`

Skill本体は `skills/` に保持する。
