# 作業計画

**更新日:** 2026-09-08

## 1. 作業段階

### 第1段階 全体設計

全体設計では次を確定する。

1. サブシステム / 取引種別 / 商品の分類
2. 業務サブシステム SS01～SS42
3. 共通サブシステム CS01～CS06
4. サブシステム責務境界
5. サブシステム間関係
6. 外部関係
7. 主要データの正本
8. 代表的な業務一貫処理
9. 取引種別・商品との対応範囲

設計内容の正本は `docs/10-設計文書/01-全体設計/` に置く。

### 第2段階 サブシステム別設計

全体設計を前提として、各サブシステムの詳細設計書を `docs/10-設計文書/02-サブシステム別設計/` に作成する。

国内株式現物取引を基本シナリオとして、主要サブシステムから詳細化する。

優先順:

1. SS01 顧客属性管理
2. SS02 口座管理
3. SS03 契約・サービス管理
4. SS05 銘柄管理
5. SS06 市場・営業日管理
6. SS08 制度・料率・業務パラメータ管理
7. SS42 交付書面・目論見書・同意管理
8. SS34 コンプライアンス・売買審査
9. SS09 注文・約定管理
10. SS10 余力管理
11. SS14 手数料・諸経費管理
12. SS16 顧客勘定管理
13. SS17 資金残高・入出金管理
14. SS18 証券預り・残高管理
15. SS21 清算管理
16. SS22 受渡・決済管理
17. SS23 保振加入者情報・振替口座管理
18. SS24 残高・資金照合／例外・フェイル管理
19. SS25 権利管理
20. SS26 譲渡益税・特定口座
21. SS27 配当・利金税
22. SS28 NISA・非課税口座
23. SS31 会計
24. SS32 対客帳票・電子交付
25. SS33 法定帳簿・当局／税務報告
26. CS01 外部接続
27. CS02 業務日付・バッチ統制

### 第3段階 取引種別展開

サブシステム別設計へ、次の取引種別固有規則を追加する。

- 信用取引
- 募集・売出
- 投資信託取引
- 債券取引
- 先物取引
- オプション取引
- 貸借取引
- 移管・振替
- 外国為替取引
- 権利行使

### 第4段階 商品展開

既存サブシステム別設計へ商品固有規則を追加する。

- 国内株式
- 外国株式
- ETF・ETN
- REIT等
- 国内債券
- 外国債券
- 投資信託
- 先物
- オプション
- CB・新株予約権等

## 2. サブシステム別設計書の完成条件

各設計書は最低限次を満たすこと。

- 業務機能・責務が明確
- 業務規則に出典がある
- 入力・出力が項目レベル
- 対内・対外関係が明確
- 状態・計算・主要例外が明確
- バッチ・締切・業務日付が明確
- 帳票がある場合はレイアウト・項目・出力契機が明確
- 訂正・取消・再処理が明確
- テスト観点がある
